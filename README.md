# Mi Primera Web

Página personal creada como taller de primer despliegue en la nube, para la electiva de Cloud Computing.

## 🚀 Demo en vivo

[https://mi-primera-web-rouge.vercel.app](https://mi-primera-web-rouge.vercel.app)

## 📋 Descripción

Sitio web estático simple con una tarjeta de presentación personal, construido con HTML y CSS puro, sin frameworks.

## 🛠️ Tecnologías

- HTML5
- CSS3

## 📦 Estructura del proyecto

```
Mi-primera-web/
├── index.html    # Página principal
├── styles.css    # Estilos
└── README.md     # Este archivo
```

## 💻 Cómo correrlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/JuanDiegoVel/Mi-primera-web.git
   ```
2. Abre `index.html` en tu navegador (o usa la extensión "Live Server" de VS Code).

## ☁️ Despliegue

El proyecto está desplegado automáticamente en [Vercel](https://vercel.com). Cada `git push` a la rama `main` genera un nuevo despliegue en producción.
